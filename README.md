# استقصاء فان جوخ — الفنون البصرية (المهمة 2 · المعيار A)

موقع تفاعلي في ملف واحد (`index.html`) عن فينسنت فان جوخ، مع تقرير A4 من ثلاث صفحات جاهز للطباعة.

إعداد: رضا أحمد يوسف · MYP-A · أستاذ المادة: أ. حسن فتيل · المادة: الفنون · المهمة الثانية (المعيار A: الاستقصاء)

- افتح `index.html` في المتصفح مباشرة (لا يحتاج إلى خادم).
- صور اللوحات روابط مباشرة من ويكيميديا كومنز، مع نسخة بديلة لكل لوحة وتصميم متدرج إذا فشل التحميل؛ ويظهر فحص الصور أسفل قسم المصادر.
- اضغط **طباعة التقرير / PDF** ثم **طباعة / حفظ PDF** (اختر "Save as PDF"، مقاس A4، وفعّل "Background graphics").
- في المعاينة اختر «ملوّن» أو «اقتصادي · حبر أقل» قبل الطباعة.
- رابط مباشر للمعاينة: `index.html#print`.
- رمز QR يشير إلى عنوان الصفحة الحالي، أو إلى `SITE_URL` داخل الملف عند فتحه محلياً (عدّله إلى رابط GitHub Pages الخاص بك).
