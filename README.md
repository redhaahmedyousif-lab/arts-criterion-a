# استقصاء فان جوخ — الفنون البصرية (المهمة 2 · المعيار A)

موقع تفاعلي في ملف واحد (`index.html`) عن فينسنت فان جوخ، مع تقرير A4 من صفحتين جاهز للطباعة.

- افتح `index.html` في المتصفح مباشرة (لا يحتاج إلى خادم).
- اكتب اسمك وصفك في أعلى الصفحة؛ يظهران تلقائياً في التقرير المطبوع.
- اضغط **طباعة التقرير / PDF** ثم **طباعة / حفظ PDF** (اختر "Save as PDF"، مقاس A4، وفعّل "Background graphics").
- رابط مباشر للمعاينة: `index.html#print`.
- رمز QR يشير إلى عنوان الصفحة الحالي، أو إلى `SITE_URL` داخل الملف عند فتحه محلياً (عدّله إلى رابط GitHub Pages الخاص بك).
